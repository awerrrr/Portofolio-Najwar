Featured · Multimodal Artificial Intelligence

Combining Image & Symptom Data to Support Disease Identification.

An end-to-end Multimodal AI system that combines visual information from chicken images with textual symptom information to support automated disease identification. As the featured and most comprehensive project in this portfolio, it brings together the skills developed across my data, machine learning, and computer vision work. The project explores how multiple data modalities can complement each other when solving a real-world classification problem.

Developed as a final academic project for the Associate Degree in Information Systems, Universitas Gunadarma (2026).

System Overview

How the Multimodal Pipeline Works

Two complementary sources of evidence are processed and brought together to support disease identification. The pipeline demonstrates an end-to-end approach that moves from raw inputs to model inference and a usable interface.

Modality 01

🖼️ Chicken Image

The image branch uses CNN-based classification to learn visual patterns associated with the target disease categories.

→
Modality 02

📝 Symptom Text

Textual symptom descriptions provide an additional information source that captures observations not directly visible in the image.

Integration

🔗 Multimodal Integration

Image and text signals are brought together so the system can reason from more than one source of evidence during inference.

Output

Potential Impact

Why the Problem Matters

  • Earlier disease indication through automated analysis of visual and symptom information.
  • More informed decisions by combining evidence that would otherwise be assessed separately.
  • Practical accessibility through an interactive application rather than a model that exists only inside a notebook.
Project Positioning
