Featured · Multimodal Artificial Intelligence

Combining Image & Symptom Data to Support Disease Identification.

An end-to-end Multimodal AI system that combines visual information from chicken images with textual symptom information to support automated disease identification. The project explores how multiple data modalities can complement each other when solving a real-world classification problem.

Developed as a final academic project for the Associate Degree in Information Systems, Universitas Gunadarma (2026).

System Overview

How the Multimodal Pipeline Works

Two complementary sources of evidence are processed and brought together to support disease identification. The pipeline demonstrates an end-to-end approach that moves from raw inputs to model inference and a usable interface.

Modality 01

🖼️ Chicken Image

The image branch uses CNN-based classification to learn visual patterns associated with the target disease categories.

→
Modality 02

📝 Symptom Text

Textual symptom descriptions provide an additional information source that captures observations not directly visible in the image.

Integration

🔗 Multimodal Integration

Image and text signals are brought together so the system can reason from more than one source of evidence during inference.

→
Output

🐔 Disease Identification

The final output supports early identification and provides an interpretable starting point for further action or expert assessment.

Key Capabilities

From Model Experiment to Usable AI System

The project brings together four capabilities that define the multimodal workflow.

🧠

Image Classification (CNN)

Learns visual patterns from chicken images using a Convolutional Neural Network approach for disease classification.

📝

Text-based Information Extraction

Uses symptom descriptions as an additional signal to capture information that may not be available from the image alone.

🔗

Multimodal Integration

Combines complementary image and text signals to support a more informed prediction.

📊

Model Evaluation

Uses classification reports and confusion matrices to inspect model behavior and performance.

Potential Impact

Why the Problem Matters

  • Earlier disease indication through automated analysis of visual and symptom information.
  • More informed decisions by combining evidence that would otherwise be assessed separately.
  • Practical accessibility through an interactive application rather than a model that exists only inside a notebook.
Project Positioning

From Model to Usable System

The project goes beyond model experimentation. It connects preprocessing, multimodal processing, evaluation, and inference into an end-to-end application that can be accessed through Streamlit.
